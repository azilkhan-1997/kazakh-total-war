# KAZAKH TOTAL WAR

SAYRAM PLANETA HOLDING — native historical strategy prototype built as an original
0 A.D. / Pyrogenesis Release 28 module. This is the continuation of the existing
project, imported from verified release source `d87603fe71a7f390862bcfb0c0be1aafaf520774`.
Module identity `kazakh_total_war`, campaign identity and schema-2 saves are preserved.

**Status:** the native Linux campaign → tactical battle → campaign/save loop has
recorded baseline evidence. The project is not a finished commercial game.
The published 0.4.0 Windows installer downloads prerequisites during installation.
A separate 1,655,605,051-byte full offline QA installer was built and extracted
successfully, but native Windows installation/gameplay and full-package
redistribution are not cleared. That QA executable is not distributed here.
