# Установка KAZAKH TOTAL WAR на Windows

Текущий выпуск 0.4.0 поставляется одним файлом **KazakhTotalWar_Setup_0.4.0.exe**.

1. Скачайте EXE со страницы игры.
2. Откройте его, выберите пустую папку и дождитесь завершения автоматической загрузки и установки.
3. Запустите игру через ярлык KAZAKH TOTAL WAR.

Интернет требуется при первой установке: до 1,65 ГБ. Windows 10/11 x64; 8 ГиБ свободного места, а при другом диске установки — ещё 2 ГиБ на системном диске для загрузки. Отдельная установка Python и распаковка ZIP не нужны.

**Запуск и установка на реальной Windows ещё не проверены.** После установки офлайн-игра предусмотрена архитектурой, но также требует приёмочного теста.

Полная актуальная инструкция: [INSTALL_EXE_RU.md](INSTALL_EXE_RU.md). Предыдущая инструкция 0.3 сохранена только для истории: `installer/LEGACY_WINDOWS_0.3.md`.
