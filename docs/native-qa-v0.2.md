# Нативная проверка продолжения v0.2

Проверено 8 ноября 2026 года на настоящем Pyrogenesis 0.28.0 (WFG PPA, Linux x64), с соответствующими официальными данными Release 28. Графическая проверка: OpenGL, Xvfb 1600×900, Mesa llvmpipe. Это функциональная проверка нативной игры. Windows, собственный EXE, аппаратный FPS и звуковое оформление здесь не проверены; запуск использовал `-nosound`.

Боевой/политический код не менялся. Кадр `14-journal-final-ru.png` показал временно неполные глифы и не выбран итоговым. После отдельного перезапуска и трёх секунд стабилизации `15-journal-verified.png` и `16-journal-second-frame.png` визуально проверены: подписи полные. Дополнительных изменений производственного кода не было.

## Воспроизведение наблюдаемого headless-боя

`evidence/v0.2/native-fixture` — отдельная тестовая модификация `ktw_qa_v02`, не часть обычной установки. Она передаёт исходный pending-снимок v0.1 из прежнего проверенного теста и тем самым испытывает миграцию; добавлено обязательное для R28 `PopulationCapType`. Единственное дополнение симуляции оборачивает Tick для чтения/вывода состояния. Оно не подменяет приказы, здоровье, потери или исход и выводит итог один раз.

Установите производственный мод и эту фикстуру в отдельный тестовый профиль R28, затем выполните:

```bash
timeout 15s pyrogenesis -mod=public -mod=kazakh_total_war -mod=ktw_qa_v02 \
  -autostart=random/ktw_battle -autostart-nonvisual -nosound
```

Код 124 означает, что timeout остановил продолжающий работать движок. Успех определяется записью `KTW_V02_HEADLESS` с `transition: campaign`, полным результатом и пустым `error`, а не самим кодом завершения. Медленный компьютер может потребовать более длительного лимита. Тестовая фикстура не доказывает загрузку нативного `.0adsave`; для неё отдельно выполнены описанные графические проверки.

## Ограничения приёмки

Это подтверждает развитие существующего Linux-прототипа и сохранение его основного цикла. Полная Part 1 / Windows-приёмка остаётся открытой. Не подтверждены отдельный Windows EXE, Steam, финальные исторические модели, голосовая шина/музыка, PBR, работа при 1000–5000 воинах, 60 FPS, все сценарии наследования, все диалоги доступности и полная локализация движка.
