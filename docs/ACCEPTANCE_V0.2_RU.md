## Исправленные граничные ошибки

- При автоматическом расчёте боя из одиночных воинов округление могло обнулить всех победителей. Теперь сохраняется один уже существующий воин победившей стороны; новая численность не создаётся.
- Несогласованные terrain/origin поля снимка могли менять правила выбора карты/отступления. Теперь снимок сверяется с провинцией, местоположением армий, соседством и потраченным движением.
- Повторный отчёт о смерти не может повторить наследование; ошибка на стадии политических последствий откатывает весь кандидат состояния.
- Старое бинарное сохранение не получает новый custom Deserialize, который изменил бы ожидаемый формат R28. Миграция выполняется после штатной загрузки.

## Ограничения этой версии

Совет пока объясняет ограниченную модель наследования, а не даёт полное управление родами. Статистики персонажей и политические веса — игровые предположения. Неизвестные исторические данные не заполняются выдуманными значениями. Будущие правители остаются в резерве; для соперника без проверенного преемника сохраняется вакансия.

Командиры используют существующие временные модели войск, без уникальных портретов/одежды. Нефатальные ранения, пленение командира, смерть в авторасчёте и на экране отступления пока отсутствуют. Кампания получает заданные послебоевые поправки морали/усталости, а не точный снимок этих тактических значений. В загруженном бою v0.1 персонаж не привязывается к воину задним числом.

При ошибке проверки загрузки блокируются команды кампании, её обработчик боя и собственные кнопки/автоматическая запись KTW. Базовая нативная симуляция сама по себе не ставится на паузу. Следует сразу загрузить предыдущее сохранение через экран восстановления. JSON API восстанавливает из отдельного валидного JSON, а не ремонтирует произвольный повреждённый `.0adsave`. Нативные резервные точки — два чередующихся автосохранения хода и контрольная точка перехода.

Графические изменения этой версии: интерфейс и диагностическая проверка возможностей; PBR, новая геометрия правителей, дистанционный LOD, музыкальные композиции и звуковые голоса не представлены как готовые. Производственные стандарты и открытые проверки — `ART_BIBLE.md`, `GRAPHICS_CAPABILITY_MATRIX.md`, `AUDIO_PLAN.md`.

## Статус Part 1 / Windows

**Part 1 остаётся незавершённой по полной приёмке:** Windows 10/11 x64 не проверен, самостоятельный EXE/инсталлятор этой игры не собран, принятие Steam не получено. В поставке есть рабочий модуль под официальный Release 28, исходники и воспроизводимый помощник установки. Linux-тесты не заменяют Windows-проверку.

Часть 2 должна расширять этот проект и сохранить открытые задачи Windows, политику, финальный исторический контент, непрерывную стрельбу на скаку, осады, звук, доступность и аппаратное профилирование. Обязательная точка продолжения — `ASTRA_PROJECT_STATE.md`.
