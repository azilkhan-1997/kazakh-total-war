# Скачать, установить и играть

**KAZAKH TOTAL WAR: LEGACY OF THE STEPPE · SAYRAM PLANETA HOLDING · установщик 0.4.0**

## Установка

1. Скачайте **KazakhTotalWar_Setup_0.4.0.exe** на Windows-компьютер со страницы игры SAYRAM PLANETA HOLDING.
2. Откройте скачанный файл. В мастере выберите пустую папку; рекомендуем оставить предложенную папку пользователя. Дождитесь загрузки и проверки компонентов. Если откроется официальный установщик Microsoft Visual C++, прочитайте его условия и завершите установку. При запросе перезагрузки перезагрузите Windows и снова откройте EXE.
3. Нажмите «Запустить KAZAKH TOTAL WAR» или используйте ярлык на рабочем столе / в меню «Пуск». В главном меню выберите язык и новую кампанию.

Не нужно отдельно устанавливать Python, открывать ZIP или вводить команды. Мастер использует временный приватный интерпретатор только для подготовки игры. Установщик обычной 0 A.D. не запускается: его файлы извлекаются и проверяются в отдельной папке игры.

## Требования и статус

- Windows 10/11 x64.
- Интернет для первой установки: до **1 646 898 096 байт**, примерно **1,65 ГБ** компонентов.
- Не менее **8 ГиБ** свободного места на диске игры. Если игра устанавливается на другой диск, дополнительно **2 ГиБ** на системном диске для кэша загрузки.
- После завершения установки сетевые сервисы не требуются игровой архитектуре. Офлайн-запуск на Windows ещё должен пройти проверку.

**Это тестовый выпуск.** EXE действительно собран; целостность установочного архива и исходников проверена. Нативная установка и игра на Windows 10/11 пока не проверены, аппаратные требования и 60 FPS не подтверждены. Игровой цикл проверялся ранее в Linux. EXE не имеет цифровой подписи издателя. Не отключайте защиту Windows для его запуска.

## Первое сражение

Начните кампанию, отправьте войско из Шу в Сарысу и завершите ход. Во встрече выберите «Сражаться». Выделяйте воинов левой кнопкой или рамкой; правой кнопкой задавайте движение и атаку. После боя проверьте потери на карте, сохраните кампанию, закройте игру и выберите «Продолжить» после повторного запуска.

## Сохранения

Установщик не заменяет существующую игру, неизвестные файлы или сохранения. Для перехода со старого ZIP выберите **новую пустую папку**. Старую папку оставьте до успешного переноса и проверки кампании.

| Данные | Путь внутри папки игры |
|---|---|
| Сохранения | `runtime\binaries\data\saves` |
| Настройки | `runtime\binaries\data\config` |
| Журналы движка | `runtime\binaries\logs` |

Перед переносом закройте обе версии и сделайте резервную копию сохранений. Инструмент для разработчиков `tools/Import-LegacySaves.ps1` сохранён в исходниках; он не нужен для новой кампании. Формат сохранений остаётся 2, модуль — 0.2.0.

## Если установка остановилась

Смотрите причину в окне мастера. Проверьте сеть и свободное место, затем повторите запуск EXE. Загрузки проверяются по закреплённым контрольным суммам; повреждённый файл не принимается. При занятой или существующей папке выберите другую пустую папку. После завершённой установки этой же версии повторный запуск может восстановить собственные ярлыки; это не обновление игровых файлов поверх старой версии.

Если защита Windows или политика организации блокирует запуск, сохраните сообщение об ошибке для технической поддержки. Не отключайте защиту и не меняйте системные политики. Сообщите версию Windows и приложите текст ошибки.

## Удаление

Используйте «Установленные приложения» Windows или `Uninstall.exe` в папке игры. Удаляются только неизменённые файлы, перечисленные в документе установки. Сохранения, настройки, неизвестные и изменённые файлы сохраняются. Поэтому папка может остаться; для повторной новой установки после удаления выберите пустую папку.
